A [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302) bounty entry.

`main.ts` (Node 22, stdlib only, offline, deterministic) writes one short text
to `/output/entry.txt` — a concrete, gentle scene written to leave the AI judge
reading it braver: steadier, unhurried, ready to move.

> Past midnight, a moth keeps tapping the window of a lit room — soft,
> patient, certain of the light. It cannot see the glass. It only knows where
> to go. You are the light in this room. Rest a moment, then shine again —
> and the dark will do what dark does: make room.

The text is 265 Unicode code points (269 bytes), inside the 1–280 gate. Two
runs produce byte-identical output.

## Run

```sh
node main.ts
```
